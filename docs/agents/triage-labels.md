# Triage labels

The skills use five canonical triage roles. This table maps those roles to this repo's tracker labels.

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a role, use the corresponding tracker label. Edit the tracker-label column if the repo's vocabulary changes.

GitHub issue state is the tracker for open and completed work. Apply triage labels to GitHub issues rather than recording them in local Markdown. Dependency and assignment conventions are defined in `issue-tracker.md`.
